## How to file new replies

1. Screenshot the reply (keep the name/handle and timestamp visible — that is the proof).
2. Save it as `evidence/F15.png`, `F16.png`, …
3. Add a section to `FEEDBACK_REPORT.md` in the same format: quote → translation → ✅ / 🟡 / 🔭 with the reason.
